# AI Workflow

## Introduction

Artificial Intelligence (AI) was used as a learning assistant during the development of the Medicine Reminder System. AI helped me understand concepts, solve programming problems, and improve project documentation. All final decisions, testing, and implementation were carried out by the developer.

---

## How AI Helped

### Project Planning
- Suggested the project idea.
- Helped prepare the project proposal.
- Recommended suitable project features.

### Learning and Development
- Explained HTML, CSS, and JavaScript concepts.
- Explained Node.js and Express.js.
- Assisted in connecting MongoDB with the application.
- Suggested the MVC folder structure.

### Programming Support
- Helped write sample code.
- Explained CRUD operations.
- Helped debug errors and fix coding issues.
- Suggested better coding practices.

### Git and GitHub
- Guided repository creation.
- Explained Git commands.
- Assisted with commits and pushing code to GitHub.

### Documentation
- Helped prepare the README file.
- Helped write the implementation plan.
- Assisted in creating project documentation.

---

## Developer's Contribution

The developer:
- Understood the project requirements.
- Wrote and tested the project code.
- Customized the application according to the project goals.
- Verified the correctness of the generated code.
- Managed the GitHub repository.

---

## Conclusion

AI was used as a supportive learning tool throughout the project. It improved development speed and understanding, while the developer remained responsible for implementing, testing, and maintaining the final project.
