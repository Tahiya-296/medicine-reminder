# Project Overview

Medicine Reminder System is a web-based application that helps users remember to take their medicines on time. Users can create an account, add medicine schedules, edit or delete reminders, and mark medicines as taken.

The system aims to reduce missed doses and improve medication management through a simple and user-friendly interface.

---

# Why This Project?

Many people forget to take medicines at the correct time, especially elderly people and patients taking multiple medicines.

This project provides an easy solution by allowing users to manage their medicine schedules in one place.
